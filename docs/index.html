NDN Pipeline

NDN Pipeline is a private analysis tool that tracks how videos on the Nine Degrees North (NDN) YouTube channel perform. It reads public video numbers, and, only if the channel owner clicks Allow, read-only YouTube Analytics reports for the channel. It is built by Vicson Yaris and is not an official NDN product.

The reports are used for internal charts and are never sold or shared. Read the Privacy Policy to see what is collected and how the channel owner can remove access.
